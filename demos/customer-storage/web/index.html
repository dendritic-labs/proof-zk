🔐 ProofZK Identity Wallet

Problem: Apple, Google, and Samsung wallets don't support DIDs yet.

Solution: Multiple secure storage options that work today!

🌐 Recommended: Browser Wallet (PWA)

✅ Advantages:

  • Works on all devices immediately (iOS, Android, Desktop)
  • Uses device biometrics (Face ID, Touch ID, PIN)
  • No app store approval needed
  • Secure (WebCrypto API + IndexedDB encryption)
  • Can be installed like a native app

⚠️ Limitations:

  • Requires internet for initial setup
  • Less "official" than native wallets
Browser Demo:
1. Customer visits proofzk.com/wallet
2. Creates DID with device biometric
3. DID stored encrypted in browser
4. Works across all airline websites
Status: 🟢 Ready to implement

📱 Native Mobile Apps

✅ Advantages:

  • Deep device keychain integration
  • Native biometric security
  • Feels familiar to users
  • Offline capability

⚠️ Limitations:

  • App store approval process
  • Separate iOS/Android development
  • Users must download and trust new app
Native App Integration:
iOS: Keychain Services + Secure Enclave
Android: Android Keystore + TEE
Windows: Credential Manager + TPM
Status: 🟡 6 months to implement

📷 QR Code Backup/Transfer

✅ Advantages:

  • Easy device-to-device transfer
  • Physical backup option
  • Works with any QR scanner
  • Family sharing capability

⚠️ Limitations:

  • User must remember password
  • QR codes must be kept secure
  • Not primary storage method
QR Transfer Process:
1. Export encrypted DID as QR code
2. Scan QR on new device
3. Enter password/biometric
4. DID imported and ready to use
Status: 🟢 Ready to implement
